# Nova Hackathon — Image-to-3D Exploration

**Event:** Nova CMU AI Hackathon (ScottyLabs)  
**Date:** November 7, 2026  
**Location:** Carnegie Mellon University, Pittsburgh, PA

## Project direction

Explored a workflow for converting reference images into 3D assets that could ultimately be viewed and edited in Blender.

## Technical areas explored

- Image-to-3D generation tools and their availability/cost constraints
- Local NVIDIA GPU-based generation as a potential alternative to paid services
- Blender-compatible model export as a target output
- Hackathon-provided OpenRouter API access

## Status

This page documents the hackathon exploration, **not a verified working end-to-end implementation**. Source code, screenshots, generated 3D meshes, and a reproducible setup have not yet been added to this repository.
